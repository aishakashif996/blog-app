# Inkwell – Responsive Blog Application

A front-end blog app built with plain HTML, CSS and JavaScript.

## Pages
- `index.html` – Home, search and read posts
- `login.html` / `register.html` – account forms with validation
- `dashboard.html` – your posts, with edit and delete
- `create-blog.html` – write or edit a post

## Run locally
Open the folder in VS Code and start **Live Server** on `index.html`.

## Notes
Accounts and posts are saved in the browser's `localStorage`. This is a learning project: passwords are not encrypted, so do not use real ones. A backend (for example FastAPI) can replace `localStorage` later.
